# Release security checklist

| Control                                                             | Evidence                                                                                                                                                                                                               | Status                                              |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Protected workspace and least-privilege action access               | PostgreSQL identity, permission, staff, report export, and administration tests. Edge exercises sign-in, password change, Viewer denials, and revocation.                                                              | Verified locally                                    |
| Password storage, temporary passwords, TOTP, and account throttling | Argon2id, one-use challenges, session rotation and revocation, progressive throttling, production Owner enrollment. Auth and TOTP tests.                                                                               | Verified locally                                    |
| Recovery email, origin and TLS                                      | Email tests with a simulated sender, production config validation, request origin checks, and CSP/HSTS tests. A delivery test against the target SMTP relay remains required.                                          | Target verification pending                         |
| Replay protection and business-level authorization                  | PostgreSQL integration tests cover concurrent number allocation, idempotency, dispatch permissions, cheque reversals, period locks, and rollback. Export routes enforce live permissions and throttle requests.        | Verified locally                                    |
| Financial history and data minimization                             | PostgreSQL triggers protect append-only tables. Audit snapshot redaction, request ID mapping, and route-template logging tests cover credential exclusion.                                                             | Verified locally                                    |
| Database network isolation                                          | The application binds to Windows loopback and separates application, schema, and backup roles. Apply the grants and inspect rules on the target Windows Server.                                                        | Target verification pending                         |
| Backup confidentiality and recovery                                 | Windows backup jobs use age with a dedicated public recipient. The restore drill checks data, omitted authentication records, digest, recovery, and a fresh destination. See [Backup and recovery](BACKUP_RESTORE.md). | Local drill and target rehearsal tracked separately |
| Dependency and secret scanning                                      | Local `npm audit` reported zero vulnerabilities and gitleaks found no secrets. The Windows CI workflow repeats these checks.                                                                                           | Verified locally. Hosted CI pending.                |
| Windows service lifecycle and HTTPS                                 | The [Windows runbook](RUNBOOK.md) covers service accounts, automatic startup, restart, rotation, Caddy, firewall, and update rollback. Verify the service and certificate from the target network.                     | Target verification pending                         |
| Retention and incident response                                     | Audit, logs, encrypted backup retention, and recovery steps are documented. The organization confirms detailed retention periods, access, and notice requirements.                                                     | Owner sign-off pending                              |
